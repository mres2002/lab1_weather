DevOps П02 - Автоматизация получения данных о погоде в Linux
Описание работы
Практическая работа по автоматизации в Linux. Скрипт получает данные о погоде (температуре и влажности) для указанного города и обновляет веб-страницу nginx.

Структура репозитория
├── weather.sh # Основной скрипт получения погоды ├── setup_nginx.sh # Скрипт установки nginx ├── setup_cron.sh # Скрипт настройки cron ├── README.md # Документация └── screenshots/ # Скриншоты выполнения работы

Требования
Ubuntu/Debian Linux
curl
jq
nginx
cron
Установка
Установите nginx:
./setup_nginx.sh
